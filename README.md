# Personal Portfolio Website

A responsive student portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, theme toggle, and contact form feedback

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Create a GitHub repository named `personal-portfolio`.
2. Upload all four files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published URL to appear in the Pages section.

## Customize
Replace the sample project descriptions and social links with your real work before submission.
